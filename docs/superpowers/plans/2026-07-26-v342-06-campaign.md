# V3.4.2 P6: Invocation, Usage, Budget, and Campaign

## Model invocation and usage

One ModelInvocation module adapts AG2 Classic, OpenAI-compatible direct calls, and CLI providers. SDK internal retries are disabled; Tenacity owns logical retry. Each attempt records UsageEnvelope before response parsing, including invalid JSON, empty output, fallback, timeout, and exceptions.

Usage records provider/profile, request and response model, call/attempt IDs, cache/reasoning tokens, cost metadata, outcome, stream/fallback state, and raw-usage hash. Missing values are null with `REPORTED`, `ESTIMATED`, or `UNKNOWN`; they are never zero or a fixed 3000-token estimate.

Budget reserves atomically before a call using maximum input/output and price bounds, then settles afterward. UNKNOWN usage keeps the full reservation. Streaming remains disabled until partial/interruption accounting is proven.

## Campaign controller

Campaign work items, cycle state, budget, roster, lease, pause, and resume live in OperationalJournal; no queue JSON is added. ExperimentTask is an input DTO. Campaign and Cycle keep domain-specific states rather than a universal FSM.

Each cycle performs:

```text
reserve -> safe context -> freeze proposal/spec/roster/generation
-> execute -> evidence -> Learning Commit -> settle
-> information-gain decision -> next-cycle decision
```

Only a successful eligible commit enters the next cycle. Invalid, tainted, Final Holdout, and `NO_MATERIAL_FINDING` content does not.

Roster manifests bind provider/profile/model/role/prompt/config/capability. A required-member or response-model drift blocks the Campaign; no silent model substitution or roster reduction is allowed.

Budget covers tokens, API cost, wall time, cycle count, tool attempts, data exposure, and disk growth. CapitalTracker becomes an analytics projection only. Cycle leases use campaign/cycle IDs, fencing, host, PID, process creation time, and monotonic heartbeat; mtime alone never reaps a lease.

Pause/STOP adapters request pause at a safe cycle boundary and never kill a running task. Dry run uses a separate namespace and budget but executes the same protocol/scope/conflict preflight; it writes no formal Packet, Ledger, Registry, or Memory.

`run_research.py` owns Campaign/status/audit commands. `run_research_cycle.py`, AutonomousRunner, AutomationController, EvolutionLoop, sqnav/backlog loops, TaskQueue, STOP, and status files are legacy adapters only.

## Gate and rollout

Test usage success/missing/fallback/timeout/invalid JSON, double-retry prevention, unknown cost, concurrent budget reservations, illegal transitions, duplicate cycles, roster drift, fencing and PID reuse, crash resume, pause boundaries, dry-run isolation, legacy quarantine, and an offline two-cycle proof that committed scoped learning enters the next context.

Implementation uses fake providers only. A real Campaign requires the separate C0-C3 rollout authorization in the index.
