# V3.4.2 P5: Scoped Learning and Bounded Context

## Claim scope and gating

ClaimScope includes mechanism, usage mode, market regime, time window, universe, liquidity bucket, label/protocol family, and generation family. LearningGate computes `EXACT`, `SUBSET`, `OVERLAP`, or `DISJOINT` mechanically.

- exact execution identity may hard-block repetition;
- semantic similarity is a warning only;
- PARTIAL applies only to the intersecting scope;
- disjoint scope does not block.

Conflicts are classified as reproducibility failure, scope/protocol conflict, data drift, or legacy evidence conflict and carry a resolution owner and actor event. `universal_factor_rejection` defaults false and may be derived only from sufficient strict multi-scope evidence; a manual true value is rejected.

Reopen is predicate-driven: new mechanism/usage/regime/time/universe/liquidity, data drift, stronger evidence, or a declared research gap may qualify. A manual bypass boolean does not.

## Context projection

ContextProjection is the sole V3.4 fact input. Existing MemoryRouter, project-state compilation, recent-file scan, and `rglob` become one-time legacy adapters and leave the hot path.

ContextAssembler produces role-specific structured views preserving scope, evidence grade, taint, invalidation, reopen, and lineage. Compression is deterministic and relevance/information-gain based. Per model/cycle, Learning Memory is at most 1500 tokens and control metadata at most 500 tokens. If critical fields cannot fit, return `CONTEXT_BUDGET_EXCEEDED`; never silently truncate them.

Known models use tiktoken or the AG2 tokenizer adapter. Unknown tokenizers are conservatively ESTIMATED, not `len(text)`. KBase/source text enters as structured untrusted data and cannot confer capability; prompt-injection fixtures are mandatory.

Negative learning can recommend avoid, soft penalty, anti-factor, regime-conditional use, or future experiments. Without strict forward validation it cannot become a production hard gate.

## Gate

Test scope intersections, PARTIAL, conflict and reopen, parent invalidation, prompt injection, taint exclusion, large ledgers, token overflow, deterministic output, absence of hot-path recent-file scans, and useful negative-learning guidance. Then freeze, inventory, review, and close.
